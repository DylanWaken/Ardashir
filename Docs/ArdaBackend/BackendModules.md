# ArdaBackend provider modules

The maintained chapter is [Backend modules](backend-modules.html). It covers the universal provider/device contracts, exact and compatibility-class selection, link-time registration, NVRHI Vulkan and D3D12 sample modules, external engine devices/resources, shader compiler hooks, ownership, threading, failure analysis, and a worked custom-module skeleton.

Exact public declarations are centralized in the [backend-module API component](api-reference.html#api-component-backend-modules).
