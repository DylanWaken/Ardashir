Backend documentation

Find the guide that fits your task

Find the appropriate module guide and keep authored pages, compiled examples and the canonical API inventory synchronized.

Start at the overview. The backend guides include:

  • Resource recipes: every RHI resource kind, allocation and ownership, with usage examples.
  • GPU allocator: device-wide heap and resource reuse, submission leases, retention controls, diagnostics, and the backend memory planner.
  • Capability recipes: every predicate in the native capability conformance matrix, its guard and executable workload.
  • How CUDA works with graphics: general concepts, shared memory, graphics/CUDA handoffs, execution modes, lifetime and performance.
  • CUDA operands and both launch methods: precompiled typed variants, registered and triple-chevron launches, runtime validation, RDG scheduling and submission lifetime.
  • GPU validation setup: local provisioning, discovery, unavailable-layer skips and failure diagnosis.
  • Command validation, native resource admission and sparse retirement, and bounded GPU fault snapshots: implemented audit contracts and failure handling.
  • Unreal RHI audit: current defect ledger, lifetime fixes, missing features and implementation/defer decisions against local Unreal 5.8.1.
  • Complete examples: compiled test helpers, shared fixtures, HLSL and artifact registrations.
  • Canonical API reference: exact symbols and contracts, readable without JavaScript; JavaScript adds search and filtering.

Keeping the docs synchronized

Edit public header comments to update the ArdaBackend, ArdaDependencyGraph, or ArdaNativeCompute API contracts. Regenerate the inventories and the static reference sections together so both versions provide the same declarations and links.

Skills/document-codebase/scripts/backend_recipes.py owns recipe explanations and selects literal code excerpts from compiled tests. It reads resource kinds from ArdaRHIResource.h and capability predicates from ArdaExtendedRHIParityTests.cpp, failing if any kind or predicate lacks coverage. recipe-coverage.json is a generated audit artifact.

The generator imports cuda_recipes.py and cuda_build.py for the operand/build/deployment guide and cuda_graphics.py for the general CUDA/graphics chapter. Edit those sources and regenerate their HTML. Examples/ArdaCudaDirectLaunch.cu is a documentation-only CUDA host helper embedded literally in the operand guide; it requires application-owned CUDA mappings and a stream and is not an implemented RHI adapter or backend GPU test. Its standalone Examples/CMakeLists.txt demonstrates build-time CUDA compiler discovery. See nvcc lookup and runtime packaging: users of a packaged application do not need nvcc installed.

Run from the repository root with Python 3.10+ and Node.js on PATH:

python Skills/document-codebase/scripts/sync_api_inventories.py
python Skills/document-codebase/scripts/backend_recipes.py
python Scripts/Docs/SyncGraphNodeRecipes.py
python Scripts/Docs/arda_graph_essay/build.py
python Scripts/Docs/HtmlDocumentation.py --write
python Scripts/Docs/HtmlDocumentation.py --check
python Skills/document-codebase/scripts/sync_api_inventories.py --check
python Skills/document-codebase/scripts/backend_recipes.py --check
python Scripts/Docs/SyncGraphNodeRecipes.py --check
python Scripts/Docs/arda_graph_essay/build.py --check
python Scripts/Docs/arda_graph_essay/validate.py
python Skills/document-codebase/scripts/validate_docs.py --verbose

Serve the repository with python -m http.server 8873 --bind 127.0.0.1 and open http://127.0.0.1:8873/Docs/ArdaBackend/ to check subpath hosting. Check mobile/desktop reflow, keyboard navigation, glossary focus, API search and JavaScript-disabled reading after layout changes. Source-backed examples still need native GPU tests; a skipped capability is not an executed test. See the validation guide before interpreting GPU results.
