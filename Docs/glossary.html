Persistent compiled shader bytecode paired with input identity metadata so reusable results can be validated.

In Ardashir: ArdaBackend stores DXIL or SPIR-V beside a .arda-key sidecar in the configured user cache and atomically republishes stale or missing artifacts when policy allows.

Persistent pipeline cache

Graphics

Driver-native pipeline optimization data saved to disk and reused by later process executions.

In Ardashir: ArdaBackend stores backend-tagged D3D12 pipeline-library or Vulkan VkPipelineCache payloads separately from its in-memory PSO LRU.

Stable semantic key

Computer science

A deterministic identifier derived from meaning-bearing content rather than process-local addresses.

In Ardashir: ArdaBackend hashes shader bytecode, layouts, formats, and fixed state to address native persistent pipeline entries across executions.

D3D12 pipeline library

Graphics

A Direct3D 12 object that serializes and retrieves driver-compiled pipeline state by name.

In Ardashir: The native D3D12 module uses stable semantic keys as ID3D12PipelineLibrary names.

VkPipelineCache

Graphics

A Vulkan object carrying implementation-specific data that may accelerate pipeline creation.

In Ardashir: The native Vulkan module initializes it from validated persistent bytes and saves updated data at shutdown.
