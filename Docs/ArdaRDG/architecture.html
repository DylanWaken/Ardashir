Learning objectives

Distinguish node definitions, persistent instances and native plans, and trace their identities and lifetimes.

Definition, instance, plan

FArdaNodeRegistry owns immutable named definitions; graphs own typed instances and snapshots. ArdaInductor resolves edges, culls work, infers pipelines, selects queues and plans storage. Native recording and barrier lowering remain private implementation details.

Stable identities and ownership

Handles contain graph identity, index and generation. Foreign, deleted and abandoned-edit handles are invalid. Instances retain definitions, parameters and imports. Frame slots retain physical storage, CUDA caches, readbacks and timestamps. Tickets retain completion state after slot reuse.

Value causality

A resource has one producer, and readers depend on it regardless of attachment order. External inputs may have no producer. Explicit edges describe non-resource effects. Pure joins and stage-only nodes contract dependencies without empty GPU submissions. Unobserved work is culled.

Compile and replay

Successful edits publish a revision; failed edits remain repairable or cancellable. The retained program replays until semantics change. ArdaInductor assigns legal queues, forms CUDA batches and evaluates cost/allocation plans. Stage inference crosses intermediates but stops at upstream consumers of the same pipeline family. The compilation chapter derives each scheduling algorithm and traces the accepted plan into native execution.

Native execution

Submit() selects a frame slot and submits ordered native work. Wait() completes tokens and publishes outputs. Execute() performs both. Begin-edit and destruction retire this graph’s outstanding submissions.

External synchronization

Serialize graph edits and submissions. Independent recording waves may run concurrently, so callbacks must avoid unsynchronized shared mutation. Physical reuse needs GPU completion ordering, not merely non-overlapping CPU list positions.

Chapter summary

The persistent graph owns semantics; ArdaInductor derives a retained program whose frame tickets preserve completion lifetime.
